# Screenshot Home Assistant

PNG autentici del frontend HA 2026.10.4, con dati esclusivamente sintetici.
Acquisiti con Playwright/Chromium dal codice 0.4.0; non dimostrano una prova con
account Mitsubishi o pompa reale.

Plancia, wizard e assistenza sostituiscono le precedenti illustrazioni mantenendo
i nomi `dashboard-preview.png`, `wizard-preview.png`, `support-preview.png`.
I file `diagnostics-collaudo-*` mostrano avvio, esecuzione, completamento, stop,
errore storage e varianti mobile/tema scuro. Nessun ritocco di stati o percentuali.

Versioni, viewport, politica privacy e comandi di rigenerazione nella
[procedura screenshot](../SCREENSHOT_COLLAUDO.md). Il generatore HTML storico
produce ora soltanto illustrazioni ignorate in `.tools/`, non questi PNG.
